this data includes input layers into the COTS outbreak model produced as part of CCIP-RT-06

an updated version of the model is now detailed in a pre-print at https://doi.org/10.32942/X2J391

some of the static predictors in the file reefVarsConstGithub.csv were provided by the authors of "Larval connectivity and water quality explain spatial distribution of crown-of-thorns starfish outbreaks across the Great Barrier Reef" (Matthews, Mellin, Pratchett, 2020), some of which were themselves derived from the dataset "High‐resolution characterization of the abiotic environment and disturbance regimes on the Great Barrier Reef, 1985–2017" (Matthews et al., 2019), and so are available there
